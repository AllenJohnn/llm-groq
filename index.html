HOW IT WORKS

One room. A few clear steps.

Use the devices you have to run a model that is too large for one browser alone.

  1. 01

    Create a room

    Open a room on the device you want to use for chat.

  2. 02

    Connect your devices

    Join with the room code so compatible devices can share model layers.

  3. 03

    Choose a model and ask

    Check memory readiness, start the model, then follow the answer and its speed.

LOCAL FIRST

Know where your prompt goes.

When you run a model locally, inference happens across the devices in your room. If you choose cloud mode, the selected provider handles the prompt.
